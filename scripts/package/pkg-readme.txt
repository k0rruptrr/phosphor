PHOSPHOR - экранная заставка для Windows 10 / 11
=================================================

Что это
-------
Заставка для экрана. Когда компьютер простаивает, вместо обычной картинки
появляются текстовые сцены из символов (матрица, звёздное небо, трубы,
огонь, аквариум, погода и др.), выведенные как на старом ЭЛТ-мониторе.
Отдельной программы запускать не нужно: всё работает как заставка.
Ничего не нужно устанавливать заранее (.NET и прочее уже внутри).


Как установить
--------------
1. Распакуйте архив: правый клик по архиву -> "Извлечь все".
   Запускать установку нужно из распакованной папки, а не прямо из архива.
2. Откройте папку и сделайте двойной клик по файлу "Установить.bat".
3. Windows может показать синее окно "Windows защитила ваш компьютер"
   (SmartScreen, "неизвестный издатель"). Это потому что программа не
   подписана сертификатом. Нажмите "Подробнее" -> "Выполнить в любом случае".
4. Откроется чёрное окно с ходом установки. В конце оно скажет "Готово".
   Нажмите любую клавишу, чтобы закрыть окно.

После установки заставка включается через 5 минут бездействия.


Как открыть настройки
---------------------
Вариант 1: правый клик по рабочему столу -> "Персонализация" ->
"Экран блокировки" -> "Параметры заставки". Выберите "PHOSPHOR" и нажмите
"Параметры".

Вариант 2: нажмите Win+R, введите  control desk.cpl,,@screensaver  и Enter.

В настройках есть:
- город для погоды (по умолчанию Москва);
- выбор сцен и фильтров (какой "экран" имитировать);
- диммер (затемнение экрана через заданное время).

Кнопка "Сохранить" записывает настройки в файл phosphor.json (он лежит в
папке %LOCALAPPDATA%\Programs\Phosphor).


Интернет
--------
Заставка ходит в интернет за новостями, погодой, телетекстом и
спутниковыми данными. Эти данные сохраняются на диске (кеш), чтобы не
качать их каждый раз. Кеш лежит в папке
%LOCALAPPDATA%\Phosphor\cache
Если интернет не нужен, снимите галочку сети в окне настроек (или поставьте
"enabled": false в разделе "network" файла phosphor.json). Тогда сцены
работают на кеше или без новостей и погоды.


Как удалить
-----------
Сделайте двойной клик по файлу "Удалить.bat" и подтвердите действие.
Прежняя заставка Windows вернётся. Папка с программой и файл настроек
будут удалены. Кеш из папки %LOCALAPPDATA%\Phosphor\cache скрипт не
удаляет: его можно удалить вручную, если нужно.

Если хотите сохранить свои настройки, откройте PowerShell в этой папке и
выполните:
  powershell -ExecutionPolicy Bypass -File uninstall.ps1 -KeepConfig


Что изменяется на компьютере
----------------------------
Установка не трогает системные папки и не требует прав администратора.
Меняется только:
- папка %LOCALAPPDATA%\Programs\Phosphor (программа, настройки, резервная
  копия прежних настроек заставки);
- настройки заставки текущего пользователя Windows (выбор заставки и
  время ожидания).
Кеш данных из интернета лежит в %LOCALAPPDATA%\Phosphor\cache (см. выше).
Других программ, служб и записей в автозапуск установка не добавляет.


Если что-то не работает
-----------------------
- Новости и погода не грузятся: антивирус или фаервол (например, Fort
  Firewall) может блокировать сеть. Разрешите доступ для файла
  %LOCALAPPDATA%\Programs\Phosphor\Phosphor.scr
- Лог последнего запуска: файл %TEMP%\phosphor.log (его можно открыть в
  Блокноте).
